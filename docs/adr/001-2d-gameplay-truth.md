# ADR-001：2D Gameplay 作为玩法真源

**状态：Active**

## 决策

Biome Epoch 使用二维逻辑层维护玩法权威状态。

2.5D / 3D 层负责表现，不反向成为 Gameplay Source of Truth。

## 原因

项目需要在保留二维玩法、碰撞、世界数据和 AI 逻辑的同时，持续调整 2.5D 纸片表现。

将两者分离后，视觉迭代不会要求重写核心玩法规则。

## 影响

- 视觉坐标必须通过桥接层映射；
- 视觉偏移不能写回逻辑坐标；
- 表现与碰撞不一致时优先检查 Mapping / Bridge；
- Gameplay 系统不能直接依赖 3D 表现对象作为权威状态。
